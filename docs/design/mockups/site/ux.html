01新访客，没装客户端

首页看演示窗口商店搜索、筛选、排序缩小范围状态在地址里详情点「安装」没有找到客户端：复制命令或下载下载页记着来自哪个包首次打开

02已装客户端，安装一个包

详情安装窗口包名与类别、发布者、装到哪个 agent、要填的值进度逐步打勾已安装列表和详情显示「已安装」

网页无法确认本机装了什么，这里的「已安装」是原型模拟的状态。安装窗口只列 agent 复选框和要填的值，不展示会执行的内容。

03全局搜索

按 / 或 ⌘K或点导航里的搜索输入前最近查看、建议、页面输入按类别分组，↑↓ 选择没有结果正在其他来源查找… → 没有找到回车进详情；Esc 关闭，焦点还回去

04浏览商店

加载中骨架列表类别 + 排序点一行快速查看抽屉展开为整页没有结果目录连不上重试

05登录与退出

点「登录」对话框选 GitHub 或 Google原型直接以 demo 登录导航出现头像个人面板、收藏、订阅、退出个人面板退出登录任何页面都能退出

06订阅 Pro

定价选周期未登录先登录，再继续结账14 天试用说明，模拟支付个人面板 · 订阅Pro 生效，续费日期管理订阅 → 取消二次确认到期后取消可恢复

开关、复选框Space

待定问题需要你拍板。

浅色主题

现有站点支持深浅切换。原型只做了深色；光晕在浅色底上要另外设计。

客户端是否跟随这套视觉

原型里的客户端窗口是按新方向画的示意，不是现在的客户端界面。

更多 agent 的名单

页面上只亮了 Claude Code 和 Codex，另有一个「更多即将支持」的占位。名单由你提供后再加。

收藏

原型按「登录后可收藏」做了。现有产品里评价和旧的条目接口已经去掉，收藏是否上线由你定。

网页上的「已安装」

原型为了走通流程显示了，并标为模拟。上线时网页是否显示、依据什么显示，需要决定。

结账页

现在点升级直接跳到 Waffo。原型多了一屏订单确认，用来放试用说明；是否保留由你定。
