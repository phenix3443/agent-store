# 新视觉原型

静态 HTML 原型，不参与构建。用任意静态服务器打开，例如在本目录运行 `python3 -m http.server`。

| 目录 | 内容 |
|---|---|
| `site/` | 网站的完整交互原型。入口 `index.html`，交互说明在 `ux.html`。中英文在导航里切换，也可以在地址后加 `?lang=zh` 或 `?lang=en`。右下角的「原型控制」用来切换登录、客户端、套餐等模拟状态 |
| `client-app/` | 桌面客户端的完整交互原型。入口 `index.html`（`#/welcome` 是首次启动，`#/discover` 直接进发现），交互说明在 `ux.html`，从代码整理的功能清单在 `INVENTORY.md`。右下角的「原型控制」可以切换登录、套餐、检测到的 agent、窗口样式，以及模拟网页发来的安装链接 |
| `../tiles/tiles.html` | 三个视觉方向的样片。选定的是 C（光谱） |

文案集中在 `site/i18n.js`，示例数据 `site/data.js` 取自测试环境目录的真实条目，价格在 `site/plans.js`。

网站原型里有三样东西现有产品没有，属于提案：收藏、网页上显示「已安装」、独立的结账页。客户端原型里新增的设计和待定问题列在 `client-app/ux.html` 第五节。用量页的数字是示例数据。
