Agent Store 新视觉：三个方向

三张样片放的是同一份内容：导航、首屏、安装预览窗口、商店卡片和几个控件，只有视觉不同。都是深色，都用 Agent Store 自己的名字和配色，没有搬参考站的标志、红色和文案。挑一张，或者说「A 的版式配 C 的颜色」这样的组合。

A · 夜航

精密 / 安静 / 专业

离参考站最近：冷黑底、悬浮圆角导航、居中粗体标题、小而亮的按钮，只有产品窗口背后一处冰蓝色的光。冒险的地方只有那一处光，其余全部克制。

B · 图版

克制 / 工程感 / 可信

保留现在这套的骨架（墨线、直角、套准十字、等宽大写标签），只换成深色底和参考站那种一节讲一件事的叙事版式。没有光晕和圆角，改动最小，但离「像 Raycast」也最远。

C · 光谱

丰富 / 有活力 / 像一家商店

技能、MCP、供应商各有一种颜色（紫、蓝、绿），卡片和首屏的光都跟着类别走，圆角更大。参考站的扩展卡片就是这个思路。最热闹，也最需要管住颜色的用量。

三张的差别

A 夜航B 图版C 光谱
颜色冷黑 + 一种冰蓝暖黑 + 纸白，没有彩色紫调黑 + 三种类别色
形状圆角 8 / 14px直角、细线圆角 10 / 18px
光效只在产品窗口背后没有首屏和每张卡片
标题居中、粗体靠左、中等字重居中、特粗
和现在的距离整套重做换底色和版式整套重做，另加类别配色
主要风险容易做得和很多深色产品站一个样你可能觉得还是不够像颜色多，列表页容易显得花

定方向时还要你回答的三件事

  1. 选哪一张，或者怎么组合。
  2. 浅色主题还要不要。参考站只有深色；现在的站深浅都有。只做深色能省掉一半的配色和验收工作。
  3. 桌面客户端跟不跟。它现在是另一套界面，跟着换是另外一批工作。
